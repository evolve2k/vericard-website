# Vericard.digital website

This website is built with Eleventy Excellent running on 11ty.

## Development

### Install dependencies

```
npm install
```

### Working locally

Starts watch tasks to compile when changes detected

```
npm start
```

# Deployment Workflow

1. Make a local branch for your commits
2. Push branch to github
3. Create Pull Request
4. When the PR's is merged into main, changes are automatically pushed live.
